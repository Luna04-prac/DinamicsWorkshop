# ⚙️ Experiencia 5 – Fuerza de Rozamiento

Este repositorio contiene los ejercicios resueltos en **Python** correspondientes a la **Experiencia #5: Fuerza de Rozamiento**, desarrollada en el curso de **Física Mecánica**.  

El objetivo es **comprender el comportamiento de un objeto sobre un plano inclinado** y **analizar la resistencia al deslizamiento entre distintas superficies**.
